# Coffee vs. Non-Coffee Text Classification

## Project Overview
This project focuses on classifying text as either **coffee-related** or **non-coffee-related** using data from Wikipedia articles. By leveraging Python and machine learning, the aim is to distinguish between these two categories effectively.

## Key Steps
1. **Data Collection from Wikipedia**: Articles related to coffee and non-coffee topics are retrieved using the Wikipedia API.
2. **Text Preprocessing**: The data is tokenized, and relevant features are extracted using the TF-IDF method.
3. **Model Building & Training**: A Naive Bayes classifier is trained on the preprocessed text data to differentiate between coffee-related and non-coffee-related content.
4. **Model Evaluation**: The classifier is evaluated using standard metrics like precision, recall, and F1-score to measure its performance.
5. **Text Classification**: A function is provided to classify new, unseen texts into coffee or non-coffee categories.

## Technologies
- **Python**: General programming and data handling.
- **Scikit-learn**: For building the Naive Bayes classifier and handling text data.
- **Wikipedia API**: To fetch relevant articles from Wikipedia.
- **Naive Bayes Classifier**: The machine learning model used for text classification.
